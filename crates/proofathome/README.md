# proofathome

The [Proof@home](https://proofathome.org) CLI and MCP server. Point your own coding agent at small, machine-checked proof obligations for open-source infrastructure.

```sh
cargo install proofathome
proofathome config set catalog /path/to/problems
proofathome problems
proofathome setup
```

See the [repository README](https://github.com/proofathome/proofathome#readme) and [docs/cli.md](https://github.com/proofathome/proofathome/blob/main/docs/cli.md) for the full command reference.
